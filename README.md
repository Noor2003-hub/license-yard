# ساحة الليسن

لعبة تدريب على اختبار السواقة في الكويت. اللعبة بتتفتح على اللابتوب، والتليفون بيبقى دركسيون بالميل.

## الملفات
- `index.html`: اللعبة (افتحيها على اللابتوب)
- `wheel.html`: الدركسيون (بيتفتح على التليفون لما تمسحي الـ QR)

موقع ثابت (static). مفيش build ولا packages.

## الرفع على Vercel
```bash
cd license-yard
npx vercel --prod
```
أو ارفعي الفولدر على GitHub واعملي Import من vercel.com/new (اختاري Framework: Other).

## الاستخدام
1. افتحي لينك الموقع على اللابتوب.
2. امسحي الـ QR اللي في الصفحة بكاميرا التليفون، ودوسي "ابدئي" ووافقي على إذن الحركة.
3. امسكي التليفون بالعرض ودوسي "سنتر".

تتبع العين بيستخدم كاميرا اللابتوب (MediaPipe) عشان يعرف إمتى بتبصي في المرايات. لو الكاميرا مقفولة أو مشتغلتش، المرايات بتتحسبلك أوتوماتيك.

التليفون واللابتوب بيتكلموا مع بعض مباشرة عن طريق PeerJS (WebRTC). لازم الموقع يتفتح بـ https عشان حساس الميل يشتغل، وVercel بيعمل ده لوحده.
